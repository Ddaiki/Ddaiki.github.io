# データ仕様（コクピット）

`companies.xlsx` が**マスター**です。会社を追加・編集したら、このファイルを差し替えて push してください。
push されると GitHub Actions（`data` ワークフロー）が自動で `companies.json` に変換します。

## companies.xlsx の列（順不同・列名で対応）

| 列名 | 内容 | 必須 | 用途 |
|------|------|:----:|------|
| 会社名 | 正式名称 | ◯ | 表示 |
| フリガナ | 社名カナ | | 並び替え |
| 法人番号 | 13桁の法人番号 | ◯※ | 年金機構（被保険者数）の照合キー |
| 許可番号 | 建設業許可番号（例 `26-002465`） | ◯※ | 国交省（許可）・CIIC（経審）の照合キー |
| 大臣知事区分 | 例「京都府知事」「国土交通大臣許可」 | | 表示・集計 |
| 法人個人 | 「法人」または「個人」 | | 集計 |
| 郵便番号 | | | 表示 |
| 所在地 | 住所（先頭の都道府県で地域集計） | | 表示・地域分布 |
| 代表者名 | | | 表示 |
| 代表者フリガナ | | | |
| 資本金千円 | 資本金（千円単位の整数） | | KPI |
| Web | 会社サイトURL | | リンク |
| Instagram | InstagramURL | | リンク |
| 経審ステータス | 「有」「倒産」など | | 倒産バッジ |
| 文化財入札 | 「有」など | | メモ |
| 自社 | 自社の行に「○」 | | 自社サマリーの対象 |

※ 法人番号が無いと被保険者数の自動取得、許可番号が無いと許可・経審の自動取得ができません（その社は手動確認）。

## 自動生成されるファイル（編集不要）
- `companies.json` … xlsx を機械可読化（アプリ・スクレイパーが読む）
- `insured.json` … 法人番号 → `[{date, count}]`（被保険者数の履歴／年金機構）
- `permits.json` … 許可番号 → `{snapshot, changes[]}`（建設業許可と変更履歴／国交省）
- `keishin.json` … 許可番号 → `[{kijunbi, revenue_k, equity_k, p_score, ...}]`（経審／CIIC）
- `news.json` … 業界・関連会社ニュース（Google News）

数値の千円・万円・億円換算はダッシュボード側で行います（保存値は千円単位）。
