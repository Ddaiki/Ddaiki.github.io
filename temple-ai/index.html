Core Values

三つのコア技術

01

AIによる
屋根劣化自動診断

ドローンが撮影した高解像度画像をAIがリアルタイム解析。瓦のひび割れ・ズレ・苔の付着を自動検出し、修繕箇所を優先度とともにAR表示。熟練職人の経験知をデジタルに継承する。

  • 瓦割れ・ズレの自動検出（精度95%以上）
  • 劣化箇所のAR可視化と位置記録
  • AI概算見積もり・30年先劣化予測
02

スマートフォンで
日常管理

境内の樹木・建物・設備を一元管理するスマホアプリ。日常の巡回チェックをデジタル化し、異常の早期発見と担当者への即時通知を実現。誰でも使えるシンプルなUIで、寺社スタッフの負担を大幅に削減する。

  • 境内マップ連動の設備管理
  • 巡回チェックリストのデジタル化
  • 異常検知・アラート通知機能
03

境内全域の
デジタルツイン化

ドローンによる3Dスキャンで境内全域を精密にデジタル化。建物・庭・参道・設備の状態をリアルタイムで把握できるデジタルツインを構築し、修繕計画・防災計画・文化財記録に活用する。

  • 境内全域の3Dモデル生成
  • 経年変化の記録と比較分析
  • 防災・修繕計画への活用
Roadmap

開発ロードマップ

Phase 1

コンセプト検証・プロトタイプ

ドローン撮影フローの確立、AIモデルの初期学習、スマホUIのプロトタイプ開発。京都市内の寺院でのパイロット実施。

Phase 2

アルファ版リリース

劣化診断AIの精度向上、境内マップ管理アプリのアルファ版リリース。複数寺院での試験運用開始。

Phase 3

デジタルツイン基盤構築

3Dスキャン→デジタルツイン生成パイプラインの構築。文化財データとの連携・経年変化記録システムの整備。

Phase 4

正式サービス提供開始

全機能を統合した次世代ファシリティマネジメントプラットフォームとして正式ローンチ。全国の寺社・文化財施設への展開。
